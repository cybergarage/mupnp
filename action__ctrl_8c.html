◆ mupnp_action_postwitharguments()

mUpnpActionResult * mupnp_action_postwitharguments ( mUpnpAction * action,
mUpnpDictionary * inputs )

All declared input arguments must be supplied exactly once, with non-NULL values. Unknown names, output arguments and invalid directions are rejected before I/O. NULL inputs means an empty set. Never mutates action values or status. Exactly one HTTP attempt, including on 405; no automatic retry. Caller must keep the action/service/device alive and unchanged during call. Result remains valid after those objects are destroyed. NULL means allocation failure. Transport failure after sending may have executed a write remotely.
